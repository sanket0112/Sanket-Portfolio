# Sanket Portfolio

A complete MERN stack portfolio project.

## Features
- Dynamic Projects display fetched from MongoDB
- Contact form to send messages directly to the database
- Professional profile with downloadable resume
- Dynamic Social Cards that automatically load icons from the assets folder

## Project Structure
- `client/`: React JS frontend (Vite)
- `server/`: Node.js Express backend
- `setup-guide.md`: Contains all instructions for installation, MongoDB setup, and running the project.
